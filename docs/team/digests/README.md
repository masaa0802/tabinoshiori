# 日報の要点（Obsidian用）

ここに入るのは**振り返り用の要点だけ**。日報の全文は `../reports/` にあり、スマホで読む形は Artifact にある。

Obsidian の `旅のしおり/日時報告` はこのディレクトリを指す。

```bash
cd "$HOME/Documents/Obsidian Vault/旅のしおり"
ln -s "$HOME/path/to/tabinoshiori/docs/team/digests" 日時報告
```

1ファイル1,500字を目安にする。フロントマターのプロパティ（`重要度` `判断待ち` `稼働部門`）で絞り込めるようにしてあるので、Obsidian 側では Dataview や検索で「判断待ちが残っている日」「保守運用が動いた日」を引ける。

書式は `TEMPLATE.md` を参照。
